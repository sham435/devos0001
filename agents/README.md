# DevOS Agents

Specialized agent definitions for the Developer Operating System. Each subdirectory contains an opencode agent definition.

| Agent | Purpose |
| --- | --- |
| `coding-agent` | Generates and modifies production code |
| `debugging-agent` | Analyzes errors, stack traces, and runtime issues |
| `architecture-agent` | Designs system architecture and reviews designs |
| `testing-agent` | Writes and maintains test suites |
| `documentation-agent` | Generates docs, changelogs, API references |
| `orchestration` | Coordinates multi-agent workflows |
